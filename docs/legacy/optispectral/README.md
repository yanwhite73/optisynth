# Inherited Optispectral archive

These files were copied from the parent Optispectral project and retain their
pre-reorganisation contents. They provide compatibility-engine history, not the
current Optisynth implementation/build contract. Relative paths, old app names and
historical installation/commit instructions inside them refer to their original
context. Current instructions are in [project status](../../project/STATUS.md) and
the repository [AGENTS.md](../../../AGENTS.md).

The archive contains the original design and Claude handoff, feature priorities
and usage data, host/VST3 parameter registries, the Optimystery handoff, parameter
extension proposals and native preset-export documentation.

Qualification helpers now locate the registries here; their registry-generation
phases can update them when explicitly run. The feature-audit helper also writes
its report here. No such analysis or plugin qualification was run during the move.

Historical references to old `docs/…` locations can be resolved with the
[relocation record](../../project/document_locations_20261117.json). New research
and decisions belong in the current topic folders rather than this archive.
