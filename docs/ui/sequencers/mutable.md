[![M01: Marbles control hierarchy](../../references/ui/sequencers_20261117/M01-marbles-control-hierarchy.png)](../../references/ui/sequencers_20261117/M01-marbles-control-hierarchy.png)

## M02 — Grids control hierarchy

[![M02: Grids control hierarchy](../../references/ui/sequencers_20261117/M02-grids-control-hierarchy.png)](../../references/ui/sequencers_20261117/M02-grids-control-hierarchy.png)

manual panel/behaviour diagram. [Original image](https://pichenettes.github.io/mutable-instruments-documentation/modules/grids/images/manual.png) · [Publisher documentation](https://pichenettes.github.io/mutable-instruments-documentation/modules/grids/manual/).

**Observed:** Grids exposes map X/Y together, three stacked fill controls and separate trigger/accent outputs.

**Optisynth inference:** A rhythm-map editor should show a map position, per-voice density and accents. An ordinary step grid alone would conceal the controlling process.

## M03 — Marbles distribution shapes

[![M03: Marbles distribution shapes](../../references/ui/sequencers_20261117/M03-marbles-distribution-shapes.jpg)](../../references/ui/sequencers_20261117/M03-marbles-distribution-shapes.jpg)

**Observed:** A matrix of spread/bias knob positions is paired with output histograms and time traces.

**Optisynth inference:** Show distribution and recent output separately: intended probabilities and realised events are different evidence. This is a manual explanation, not a screenshot of a live module display.
