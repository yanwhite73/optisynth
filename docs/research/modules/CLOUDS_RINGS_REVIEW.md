# Halo and Cumulus branch review

27 November 2026, request 157. Reviewed `clouds-rings` at `1f562b0`, including a snapshot of the working changes to `app/PatchIO.h` and `app/RackEditor.h`. The installed standalone was 0.0.38. Tests below used the 48 kHz rack runtime in an isolated checkout. The UI and musical quality of the draft preset were outside the listening evidence collected here.

## Findings before delivery

1. **Cumulus can read past its pitch table at the top of the knob.** The ordinary suite accepts the expected +24 semitone result. AddressSanitizer reports a read immediately beyond `clouds::lut_quantized_pitch` in that same check. The wrapper passes the inclusive maximum to an interpolator that reads the following entry. The audio path uses the same function. Return the final table value at the endpoint and keep the existing full-scale test under sanitizers. See `src/modular/texture_clouds.cpp` lines 140 and 199.
2. **Both new rack tests ask the renderer to overrun their own buffers.** Each allocates 96,000 samples per channel and requests 512 frames on every call. The last call has room for 256. The first sanitizer run stops in the Halo test. Limiting the last call in both test fixtures, in the review copy only, let the suite reach the separate Cumulus pitch failure. This first failure belongs to the test caller. See `tests/physical_resonator_checks.h:150` and `tests/texture_clouds_checks.h:159`.
3. **A fresh Halo ignores a direct keyboard note from the rack.** With Halo as the sole output, its sympathetic-string model and no input cables, a host A3 at velocity 0.8 produced exactly zero on both channels. With a pattern sequencer cabled to Notes, the same model produced a 0.608 peak. The wrapper only accepts rack note triggers when it detects a Notes cable. Give the host note a path to the internal exciter while retaining the existing STRUM, pitch and audio-input behaviour. Cover both direct and cabled note paths. See `src/modular/physical_resonator.cpp:87`.
4. **Cumulus recalls Freeze on while the processor is recording.** Starting the rack with Freeze saved on gave a processor freeze meter of 0 after 480 samples. Switching it off and on gave 0 and 1 respectively. Initialisation restores the switch before firmware preparation clears it. The existing test creates the saved-on case but discards that render, then checks the external gate. Apply the saved switch after preparation and assert its effective state on recall. Preserving the recorded audio is a separate feature. See `src/modular/texture_clouds.cpp:50` and `tests/texture_clouds_checks.h:84`.
5. **A patch using just Halo’s Odd or Even jack loses part of the sound.** Rings mixes both halves into a single connected output and splits them when both are connected. Halo always sends one half to each mono jack. This can lose partials in mono or alternate ringing voices in polyphony. The combined stereo Out works around it. Verify one-jack and two-jack patches against the documented behaviour. See `src/modular/physical_resonator.cpp:89`. [Rings manual, controls and outputs](https://pichenettes.github.io/mutable-instruments-documentation/modules/rings/manual/#controls-inputs-and-outputs)

## What works and what was checked

Halo uses the Rings resonator and string-synth code. All 28 files under its vendored Rings directory matched the pinned upstream Git blobs byte for byte. Cumulus includes the Clouds granular, stretch, looping delay and spectral processors. Its four frozen-buffer storage slots are absent from the rack interface, which matters for pieces that depend on recalling a captured texture. [Upstream firmware revision](https://github.com/pichenettes/eurorack/tree/f4cfa7697095a28d292bff758beb51deb49b5a86) · [Clouds manual, saving and loading buffers](https://pichenettes.github.io/mutable-instruments-documentation/modules/clouds/manual/#saving-and-loading-buffers)

The optimised suite reported 552 passing checks. The two sanitizer runs stopped at the distinct errors above. The independent keyboard and Freeze probes used the same Runtime entry point as rack playback. Factory 42 in the draft does wire a 72 BPM sequence to Halo and feeds Halo’s stereo output into Cumulus. That wiring explains how the showcase can play while a newly added Halo is silent from the keyboard. Hardware A/B, native UI interaction and a listening judgement on factory 42 remain unverified by this review.

Local receipts are in `build/reviews/claude-157/probes.txt` and `build/logs/claude-review-157-{tests,sanitizer-clamped}.log`.
